A one-line roast of a gadget used every day, written for make.fun's
"One-Line Roast: The Gadget You Use Every Day" bounty.

## The roast

> My fridge texts me when the milk expires, which is great, because now even my groceries are disappointed in me.

The target is a smart fridge — a daily gadget whose "helpful" expiry
notifications feel less like a feature and more like a passive-aggressive
roommate judging you. The joke lands on a first read: the fridge is not
just smart, it is disappointed, and now the groceries are too.

## Run

```sh
python3 main.py
```

This writes the roast to `/output/entry.txt` (verified: 111 characters,
111 bytes, one line, no trailing newline), after validating it against
the gate: UTF-8, 1–200 characters, not only whitespace.
